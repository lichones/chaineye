## 1. 문제 정의 (Why)

가상자산은 이제 금융 자금세탁의 핵심 통로다. 국내에서도 보이스피싱·불법도박·마약대금이 거래소를 거쳐 비트코인으로 세탁되는 사건이 급증하고 있으나, 현장의 한계는 명확하다.

- **수사·컴플라이언스 인력의 그래프 분석 역량 격차**: 블록체인 익스플로러로 트랜잭션을 일일이 따라가는 수작업은 느리고, 다단계 세탁(peeling chain, mixing)을 사람이 눈으로 쫓기 어렵다.
- **"의심스럽다"의 근거 부재**: FIU/거래소 STR(의심거래보고) 작성 시 "왜 의심되는지"를 정량적·설명가능하게 제시하기 어렵다.
- **탐지와 리포팅의 단절**: 이상 탐지 모델은 있어도, 그 결과를 실제 수사 착수·보고서로 바꾸는 마지막 단계가 사람 몫으로 남는다.

> **본 서비스는 "탐지 → 추적 → 설명 → 리포트"의 전 과정을 하나의 AI 워크플로우로 연결한다.**

## 2. 타깃 사용자와 가치 (Who / Value)

| 사용자 | 핵심 가치 |
|---|---|
| **가상자산 사업자(VASP) 컴플라이언스팀** | STR 작성 시간 단축, 탐지 근거의 정량화·표준화 |
| **금융정보분석원(FIU)·수사기관** | 자금흐름 시각 추적 + 자동 수사보조 리포트로 초동 대응 가속 |
| **거래소 리스크팀** | 입금 주소 실시간 리스크 스코어링으로 세탁자금 유입 차단 |

## 3. 솔루션 개요 (What)

사용자가 특정 트랜잭션(또는 주소)을 입력하면 3단계로 응답한다.

1. **리스크 스코어링** — 학습된 AI 모델이 해당 거래의 불법(illicit) 확률을 0~100으로 산출.
2. **자금흐름 추적 시각화** — 대상 트랜잭션의 상·하류 흐름을 그래프로 그려, 위험 노드를 색상·경로로 강조. **추적 로직이 대상 거래에서 고위험·불법 노드(위험도 70 이상)로 향하는 의심 방향성 경로를 최대 8개까지 추출**하고, 프론트엔드는 이 경로를 **주황색 "의심 자금세탁 경로" 범례**로 하이라이트하여 다단계 세탁(peel chain·layering)을 한눈에 보여준다.
3. **AI 수사·컴플라이언스 리포트** — 위험 등급, 핵심 판단 근거(어떤 피처가 위험을 높였는지 = XAI), 권고 조치를 담은 리포트를 자동 생성(현재 템플릿 기반, LLM 연동 예정).

## 4. 데이터 (Data) — 구현 근거의 핵심

**Elliptic Data Set** (Elliptic사 공개, 익명화된 실제 비트코인 트랜잭션 그래프)

- 노드 **203,769개**(=트랜잭션), 엣지 **234,355개**(=비트코인 흐름), **49개 타임스텝**
- 노드당 **166개 피처**: 앞 94개 = 거래 자체 정보(입출력 수, 수수료, 타임스텝 등), 나머지 72개 = 이웃 트랜잭션 집계
- 라벨: **불법 2%(4,545) / 합법 21%(42,019) / 미분류 77%**

> 목업이 아니라 **실존하는 공개 실데이터로 학습·검증**하므로 "실제 작동하는 서비스" 요건을 정면으로 충족한다. (확장 옵션: 그래프 규모를 키우는 Elliptic++ / 서브그래프 단위 Elliptic2 데이터로 고도화 가능)

## 5. AI 모델 접근 (How - Model)

3주 구현 현실성과 심사 임팩트를 함께 잡기 위해 **2트랙**(라이브 추론 + 그래프 보완 모델)으로 간다.

1. **테이블 모델 (기본기·안정성, 라이브 추론)**: LightGBM을 165개 피처(time_step 제외)에 학습 → 빠르고 강력한 기준 성능 확보. 시간축 분할(학습 타임스텝 1~34, 테스트 35~49) 기준 **불법 F1 0.776 / ROC-AUC 0.936** 달성. 클래스 불균형(불법 2%)은 class weight로 대응. 지표는 **불법 클래스 기준 F1·ROC-AUC** 중심(Accuracy는 불균형 데이터라 오해 소지). **현재 라이브 추론(/score)은 이 LightGBM 단독으로 서빙.**
2. **그래프 신경망 (차별화·서사, 구현·평가 완료)**: GCN(3× GCNConv, PyTorch Geometric)으로 트랜잭션 간 연결 구조까지 학습 → "돈의 흐름"을 모델이 직접 본다는 서사. LightGBM과 동일 프로토콜(동일 시간축 분할)로 평가하여 **불법 F1 0.562 / ROC-AUC 0.892** 확인. F1이 트리 모델보다 낮은 것은 Elliptic의 165개 수작업 피처가 이미 트리에 매우 변별력이 높기 때문이며, GCN은 그 대신 **관계·구조적 세탁 신호(layering·peel chain·믹서 fan-out)**를 인코딩한다. 따라서 대체가 아닌 **보완적 앙상블 후보**로 자리매김(코드는 `app/ml/gcn/`에 독립 존재, 아직 라이브 추론/백엔드에는 미연동).
3. **설명가능성(XAI)**: SHAP로 각 판정의 기여 피처를 제시 → "왜 위험한가"를 근거로 환원.
4. **LLM 리포트 생성**: (스코어 + 상위 SHAP 근거 + 그래프 통계)를 사람이 읽는 수사·컴플라이언스 리포트로 요약. **현재는 템플릿 기반으로 리포트를 생성하며, Claude API 연동은 예정된 고도화 항목.**

## 6. 시스템 아키텍처 (How - System)

```
[웹 프론트엔드]  React + 그래프 시각화(Cytoscape.js)
      │  거래ID/주소 입력, 스코어·그래프·리포트 표시
      ▼
[백엔드 API]  FastAPI (Python)
      ├─ /score     : 학습된 LightGBM 추론 → 불법 확률  (라이브 서빙 모델)
      ├─ /trace     : 대상 노드의 상·하류 서브그래프 + 의심 자금세탁 경로(최대 8개) 추출
      ├─ /explain   : SHAP 상위 기여 피처
      └─ /report    : 템플릿 기반 수사 리포트 생성 (Claude API 연동 예정)
      ▼
[모델·데이터 계층]  라이브 모델 = LightGBM(.pkl) + Elliptic 그래프(전처리 완료)
      │   └─ [병렬 그래프 모델] GCN(.pt, app/ml/gcn/) — 구현·평가 완료, 앙상블 후보(아직 미연동)
      ▼
[배포]  Hugging Face Spaces (Docker) 또는 Render — 공개 URL 발급(예정)
```

> 서빙 경로는 **LightGBM 단독**이며, GCN은 동일 데이터로 학습·평가를 마친 **병렬 그래프 모델**로 그래프 구조 신호를 보완한다(앙상블 연동은 이후 단계).

## 7. 차별점 (Differentiation)

- **탐지에서 끝나지 않는다** — 대부분의 유사 프로젝트는 "분류 정확도"에서 멈추지만, 본 서비스는 **추적 시각화 + XAI + 자동 리포트**로 실무 워크플로우 전체를 커버. 특히 대상 거래→고위험 노드로 향하는 **의심 자금세탁 경로를 자동 추출·주황색 하이라이트**하여 다단계 세탁 흐름을 즉시 가시화.
- **현장 관점 설계** — 침해사고 대응 실무 경험을 바탕으로 "수사관·컴플라이언스 담당자가 실제로 쓰는" UX를 설계.
- **2024·2025 회차와 차별** — 과거 회차의 일반 이상금융거래 분류와 달리, **가상자산·그래프·설명가능성**이라는 신규 축.

## 10. 확장 시나리오 (범용 커스텀 가능성)

본 서비스의 핵심은 특정 코인이 아니라 **"그래프+테이블 데이터 → 위험 스코어링 → 흐름 추적 → 설명(XAI) → 자동 리포트"** 라는 범용 파이프라인이다. 데이터 계층만 교체하면 다양한 기관이 자체 환경에 맞춰 재사용할 수 있다.

| 도입 주체 | 커스텀 방식 | 기대 효과 |
|---|---|---|
| **가상자산 거래소·VASP** | 자사 입출금·온체인 데이터로 재학습 | 세탁자금 유입 실시간 차단, 트래블룰 대응 |
| **은행·금융정보분석원(FIU)** | 계좌 이체 네트워크로 그래프 구성 | 보이스피싱·대포통장 자금흐름 추적, STR 자동화 |
| **카드사·보험사** | 거래/청구 데이터에 적용 | 이상거래·보험사기 탐지(대회 예시 주제 직접 대응) |
| **타 블록체인** | 이더리움 등 체인 데이터로 확장 | 멀티체인 자금세탁 추적 |

**전제 조건(정직한 명시):** 실제 도입 시에는 ①해당 기관의 **자체 라벨 데이터·피처 엔지니어링**(Elliptic의 익명화 피처는 재현 불가), ②**인증·권한·감사로그** 등 프로덕션 보안, ③LLM 리포트의 **근거 기반 생성 + 담당자 최종검토** 원칙이 필요하다. 본 MVP는 이 확장의 **개념증명(PoC)이자 오픈 레퍼런스**로서 가치를 가진다.

**사회적 가치:** 자금세탁 추적은 보이스피싱·마약·불법도박 등 범죄수익 흐름을 끊고 피해자금 회수를 돕는 공익적 목적을 가진다. 단, 본 도구는 **수사·컴플라이언스 담당자의 근거 기반 보조 수단**이며 최종 판단은 사람이 수행한다는 원칙을 견지한다.
