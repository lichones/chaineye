1. MVP 구현 범위 *

제출 저장소에서 실제 동작하는 기능만 기재했다. 입력은 Elliptic 데이터셋의 거래 ID이며, 실시간 지갑 주소·64자리 온체인 txid 위험도 조회는 구현 범위가 아니다.

구현 영역범위상태
모델 추론LightGBM 점수, 원시 확률 기반 임계값 판정, 상위 SHAP 기여도구현 완료
그래프 조회최대 2홉 방향성 거래 인접 그래프와 검토 후보 경로(최대 8개)구현 완료
판단 거부데이터 범위 밖 입력에 unknown 반환, 점수·보고서·STR 권고 억제구현 완료
검토 리포트근거 제한 템플릿, 선택형 Claude/OpenAI 경로, 실제 생성 경로 배지구현 완료
운영 안전모델 장애 시 503 fail-closed, 합성 목업은 명시적 환경변수에서만 허용구현 완료
제외: 실시간 주소 엔터티 귀속, 제재목록 매칭, 주소 클러스터링, 거래소 KYC 연동, 멀티체인 조회, GCN 라이브 앙상블.

POST /report		generator 배지로 실제 경로 확인
판단 거부미등록 ID는 riskScore=null, label=unknown을 반환하고 생성 호출을 중단평가 불가 화면
/score, /report		/report 우회 요청도 422

화면 표시 원칙

  • 모델 양성은 “불법 확정 아님”, 모델 음성은 “정상 확정 아님”을 함께 표시한다.
  • 리포트 배지는 생성 AI provider, 결정론적 템플릿, 생성 억제를 구분한다.
  • 평가 불가일 때 기존 그래프의 초점 노드만 미평가 상태로 표시하고 자동 권고를 만들지 않는다.

3. 사용자 이용 흐름 *

1. URL 접속계정 없이 접속하고 상단의 MODEL API 배지를 확인한다.
›
2. 예시 선택검토 후보, 낮은 우선순위, 미평가 중 하나를 클릭한다.
›
3. 병렬 분석/score와 /trace를 호출해 모델 출력과 그래프를 표시한다.
›
4. 출력 통제유효 입력만 /report를 호출하고 미평가는 생성 억제한다.

흐름 A - 검토 후보

  1. 예시 70424581을 클릭한다.
  2. 모델 점수 29점, 검토 임계값 23점, “우선 검토 / 모델 양성·불법 확정 아님”을 확인한다.
  3. SHAP 피처와 2홉 방향성 인접 그래프, 검토 후보 인접 경로를 확인한다.
  4. 리포트의 “불법 거래나 자금세탁을 확정하는 결과는 아님” 문구와 생성 경로 배지를 확인한다.

흐름 B - 데이터 범위 밖 입력

  1. 예시 999999999999를 클릭한다.
  2. 점수 대신 “평가 불가”와 데이터 부재가 정상 근거가 아니라는 설명을 확인한다.
  3. 리포트 영역에서 “판단 거부·생성 억제” 배지와 STR 권고 미생성을 확인한다.

흐름 C - 낮은 우선순위

  1. 예시 114498409를 클릭한다.
  2. 모델 음성은 정상 확정이 아니라는 문구와 기존 업무 규칙 적용 권고를 확인한다.
심사자는 직접 거래 ID를 입력할 수도 있다. Elliptic 데이터에 없는 값은 임의 점수로 보간하지 않고 평가 불가로 처리한다.
사용자 흐름3 / 5

4. AI 및 데이터 처리 방식 *

처리 파이프라인

입력 txId → feature_table.parquet 범위 확인 → LightGBM predict_proba → 원시 확률 ≥ 0.225676이면 모델 양성 → SHAP TreeExplainer 상위 기여도 → edges.parquet 방향성 2홉 그래프 → 유효 입력만 근거 제한 리포트 생성
구성요소입력출력안전 통제
LightGBM익명 피처 165개불법 클래스 확률, 양성/음성시간 분할 검증·원시 확률 판정
SHAP동일 피처 벡터상위 피처·기여 방향설명과 증거를 분리
그래프거래 ID, 홉 수노드·엣지·후보 인접 경로원본 방향성 엣지만 사용
리포트점수·임계값·라벨·기여도·통계한국어 검토 지원 문장입력 외 사실 생성 금지·출처 배지

데이터 보호

  • 공개 Elliptic 벤치마크만 사용하며 개인정보·실제 고객정보·실제 지갑 주소를 저장하지 않는다.
  • CTI-Vault의 제한 정보나 비공개 주소는 공개 서비스에 포함하지 않으며 퍼블릭 익스플로러로 자동 조회하지 않는다.
  • 외부 생성형 AI를 활성화할 경우 입력 데이터가 provider로 전송된다는 사실을 운영 고지하고 Secret은 서버 환경변수로만 관리한다.

성능과 한계

독립 시간 테스트의 불법 클래스 Precision 0.698, Recall 0.723, F1 0.711, PR-AUC 0.674, ROC-AUC 0.899다. 익명 피처는 실제 기관 피처로 바로 설명할 수 없으며, GCN 과거 실험은 비교 가능한 검증이 없어 라이브 추론과 성능 주장에 사용하지 않는다.

5. MVP 검증 방법 *

심사자 검증 절차

#입력·조작예상 결과판정
1URL 접속상단 MODEL API 배지, 입력창, 예시 3개가 보임통과
27042458129점, 임계값 23점, 우선 검토, 후보 경로, 템플릿 또는 provider 배지통과
3114498409임계값 미만, 모델 음성·정상 확정 아님, 낮은 우선순위 보고서통과

5unknown으로 /report 직접 호출HTTP 422, 보고서 미생성자동검증
6모델 상태 강제 해제HTTP 503, 합성 결과 미반환자동검증

자동 검증 명령

python app/ml/verify_inference.py python app/backend/verify_api.py cd app/frontend && npm run build

검증 결과: 추론 assertion 통과, API 계약 200/422/503 통과, Vite production build 통과, Chrome 실제 화면 양성·미평가 흐름 통과, 콘솔 오류 0건.

실행 환경과 제한사항

  • 무료 Render 인스턴스는 절전 후 첫 접속이 지연될 수 있으므로 제출 URL 가용 시간에는 사전 웜업 또는 상시 실행 환경이 필요하다.
  • 실제 주소 조회가 아니라 Elliptic 정수 거래 ID만 지원한다.
  • SHAP 피처명이 익명이라 실무 의미 해석에는 기관 자체 피처 사전이 필요하다.
  • 공개 데모가 템플릿 경로이면 생성형 AI 실행으로 주장하지 않는다.
